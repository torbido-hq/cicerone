A generic, self-hosted batch recommender. It reads your interaction data, trains a hybrid rectools + LightFM model, and writes top-K recommendations per user — optionally exposed over a small read-only HTTP API. No live inference in the request path.

Tutorial Architecture All docs Source on GitHub (opens on GitHub) Beerware license on GitHub

Features

  • Batch job — cron-scheduled train and top-K write (dataset or DB I/O)
  • Hybrid strategies — collaborative (LightFM), item KNN, content cold-item fallback, popular, latest; priority or RRF fusion
  • Serve mode — read-only HTTP API over precomputed recommendations; OpenAPI at /docs
  • Policies & AutoML — eligibility filters, score boosts, time-fold backtests
  • Ops — retrain webhook, optional input poll, Prometheus metrics, Basic-Auth dashboard

Flow

Input (dataset or database) → weigh interactions → train strategies → write top-K recommendations → optional serve API / dashboard.

Dashboard

Standalone status page for the latest job run (and history with a DB output). HTTP Basic Auth; never loads the training stack.
