Pipeline

Read interactions from a dataset or database, train configured strategies, write recommendations — then optionally serve them.

Capabilities

What ships in the box

Configured through TOML. Runs in Docker. Domain-agnostic — drinks, books, courses, anything with users and items.

  • Batch job Cron-scheduled train and top-K write from dataset or DB I/O.
  • Hybrid strategies Collaborative (LightFM), item KNN, content cold-item fallback, popular, latest — fused by priority or RRF.
  • Serve mode Read-only HTTP API over precomputed recommendations; OpenAPI at /docs.
  • Policies & AutoML Eligibility filters, score boosts, and time-fold backtests to pick models per run.
  • Ops surface Retrain webhook, optional input poll, Prometheus metrics, and the status dashboard.
