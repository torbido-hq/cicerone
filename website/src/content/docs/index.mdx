## Features

- **Batch job** — cron-scheduled train and top-K write (dataset or DB I/O)
- **Hybrid strategies** — LightFM, item KNN, optional SASRec/BERT4Rec, content cold-item fallback, popular, latest; priority, RRF, or per-user blending
- **Serve mode** — read-only HTTP API over precomputed recommendations; OpenAPI at `/docs`
- **Incremental events** — webhook / DB / S3 / Redis Streams write-through between full retrains
- **Policies & AutoML** — eligibility filters, score boosts, time-fold backtests
- **Ops** — retrain webhook, optional input poll, Prometheus metrics, Basic-Auth dashboard with user-id lookup

## Flow

Input (dataset or database) → weigh interactions → train strategies → write top-K recommendations → optional serve API / dashboard.

![Diagram of the Cicerone pipeline from input events through training to recommendation output](/images/flow.svg)

## Dashboard

Standalone status page for the latest job run (and history with a DB output), plus a user-id lookup of current top-K recommendations. HTTP Basic Auth; never loads the training stack.
